SAS VS ZOMBIES — ALPHA 1.16: REACHING HORDE PROTOTYPE

Install: replace the five files in your GitHub Pages repository root with the files in this ZIP. Keep all five together, then refresh the game on your iPhone. If the old build remains cached, open the site in a private tab or refresh again.

What changed in Alpha 1.16:
- Prototyped a more human-like zombie silhouette with a neck, forward-thrust head, articulated bent arms, reaching forearms and claw-like hands.
- Added an uneven, asynchronous reaching gait while preserving smooth turning toward the player.
- Preserved the 20 procedural looks, existing death styles, blood effects and lightweight Canvas rendering.
- Added Alpha 1.16 to the home-screen VERSION LOG; keep updating it with every release.
- Retains the 700-zombie stress-test target, invulnerable player, rapid fire, unlimited ammo/grenades and pause controls.

Performance note: Alpha 1.13 handled 700 animated zombies smoothly on the tested iPhone. This prototype uses procedural Canvas drawing, with no external images or network dependencies. It has not yet been tested on-device; please test responsiveness and the 700-zombie scenario before treating the animation as final.

The zombie artwork remains procedural Canvas art, not hand-painted sprite sheets. Alpha 1.16 is a first animation prototype; further silhouette and art polish can follow your feedback. Version history is displayed on the title screen.

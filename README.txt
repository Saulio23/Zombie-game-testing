SAS VS ZOMBIES — ALPHA 1.15: HORDE VARIETY

Install: replace the five files in your GitHub Pages repository root with the files in this ZIP. Keep all five together, then refresh the game on your iPhone. If the old build remains cached, open the site in a private tab or refresh again.

What changed in Alpha 1.15:
- Expanded from 5 to 20 procedural zombie looks, selected randomly for each spawn.
- Added a broader range of skin tones, clothing and trouser colours, body silhouettes, torn-cloth details, wounds and markings.
- Retained smooth turning toward the player, varied walking rhythms, three death styles and blood effects.
- Added a VERSION LOG to the home screen. It lists this release and earlier Alpha updates; keep adding an entry whenever a new version is released.
- Retains the 700-zombie stress-test target, invulnerable player, rapid fire, unlimited ammo/grenades and pause controls.

Performance note: Alpha 1.13 handled 700 animated zombies smoothly on the tested iPhone. This update adds more procedural drawing variation but no external images or network dependencies. Please retest the 700-zombie scenario to confirm performance remains stable.

The zombie looks are lightweight procedural canvas artwork, not final hand-painted sprite sheets. Version history is displayed on the title screen.
